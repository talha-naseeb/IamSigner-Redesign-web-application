# Plan 05-01: Centralized Navigation Stepper Component & Hook Engine

## Objective
Design and implement a unified `<DocumentStepper />` component in `src/Components/DocumentPreparation/Stepper/` that consolidates the 3 separate stepper clones (`Upload Flow/Stepper/Stepper.js`, `BulkSend/Stepper/BulkStepper.js`, and `SelfSignature/Stepper/SelfSignStepper.js`) into a single configurable engine with preset step flows, unified token styling, RTL awareness, and comprehensive unit tests.

## Context
Currently, each signing flow maintains its own copy of a vertical sidebar navigation stepper:
- `src/Components/Upload Flow/Stepper/Stepper.js` (72 LOC)
- `src/Components/BulkSend/Stepper/BulkStepper.js` (74 LOC)
- `src/Components/SelfSignature/Stepper/SelfSignStepper.js` (62 LOC)

All 3 share:
1. Fixed 15% sidebar layout (`fixed left-0 top-0 z-[1035] flex h-full w-[15%] ... rtl:left-auto rtl:right-0 rtl:border-r-0 rtl:border-l`).
2. Theme-aware logo rendering (`theme === "dark" ? <Icons.IamSignerLightMode /> : <Icons.StepperLogo />`).
3. Circular step markers with completed, active, and pending states styled via `--modern-*` design tokens (`--modern-raised`, `--modern-success`, `--modern-primary`, `--modern-border-strong`).
4. Connecting vertical lines with active half-fill indicators.
5. Inconsistencies: `BulkStepper` calls `useTranslation()` while others take `t` as a prop; route path checks for templates have disparate checks (`/createTemplates` vs `/create-templates`).

## Proposed Architecture
1. **`stepperConfig.js`**:
   - Defines the standard presets:
     - `UPLOAD_FLOW`: 4 steps (Upload Document, Add Signers, Place Signatories, Send & Sign)
     - `BULK_SEND`: 4 steps (Upload Document, Add Signers, Place Signatories, Send & Sign)
     - `SELF_SIGN`: 3 steps (Upload Document, Place Signatories, Sign & Save)
     - `TEMPLATES`: 3 steps (Upload Document, Add Signers, Place Signatories)
   - Provides helper functions for resolving active and completed step states.
2. **`DocumentStepper.jsx`**:
   - Accepts `activeStep`, `completedSteps`, `flowType` (or explicit `steps` array), and optional `t` (falling back to `useTranslation()`).
   - Renders the brand logo header linking to `/home`.
   - Iterates through configured steps, rendering standard step markers, labels, and connecting lines.
   - Applies strict `--modern-*` tokens with zero decorative shadows.
   - Automatically supports RTL document direction.
3. **Backward Compatibility Wrappers**:
   - `Upload Flow/Stepper/Stepper.js`: Wraps `<DocumentStepper flowType="upload" {...props} />`.
   - `BulkSend/Stepper/BulkStepper.js`: Wraps `<DocumentStepper flowType="bulk" {...props} />`.
   - `SelfSignature/Stepper/SelfSignStepper.js`: Wraps `<DocumentStepper flowType="selfSign" {...props} />`.
4. **Re-export**:
   - Export `DocumentStepper` and `STEPPER_FLOWS` from `src/Components/DocumentPreparation/index.js`.
5. **Unit Tests**:
   - `DocumentStepper.test.js` using Node ESM test runner (`node --test`), verifying preset step counts, step label resolution, marker class resolution, and active/completed states.
