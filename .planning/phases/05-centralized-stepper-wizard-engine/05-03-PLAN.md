# Plan 05-03: Step 2 & Step 3 Wizard Architecture Consolidation & Verification

## Objective
Unify the shared navigation toolbar and controls header in Step 2 (`CanvasHeader`) and the dispatch/action summary bar in Step 3 (`DispatchSummaryBar`) under `src/Components/DocumentPreparation/`, strictly preserving all coordinate calculation and signing math. Verify all signing flows, run the complete unit test suite, and update documentation/inventory.

## Context
1. **Step 2 (Canvas Placement)**:
   - Each flow uses `Secondstep.js` and `DisplayCenterImage.js`.
   - `DisplayCenterImage.js` and `Secondstep.js` share the top toolbar (Page navigation, Zoom In/Out/Reset, Search, and Next/Previous actions).

2. **Step 3 (Review & Dispatch)**:
   - `Upload Flow/Step3/Thirdstep.js` and `BulkSend/Step3/Thirdstep.js` share folder selection (`FolderSelection.js`), signing message customisation, expiration date pickers, and dispatch button bars.
