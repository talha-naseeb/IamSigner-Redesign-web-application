# Plan 07-02: DMS Live Backend API Integration, Mock Purge, and Inventory Verification

## Objective
Verify and solidify the end-to-end integration of all DMS backend endpoints across `src/Components/DMS/`, ensure zero mock data or simulated responses remain, confirm all folder/file operations (CRUD, move, rename, download, activity, sharing, and storage) route through live `userService` APIs, and record verified status in `UI_MODULE_INVENTORY.md`.

## Context
Requirement `DMS-02` specifies:
"Real DMS backend API integration replaces all hardcoded mock data in `src/Components/DMS/`."
The DMS module provides an enterprise-grade document management experience with:
1. Root folders, subfolders, and hierarchical tree navigation (`getDmsRootFolders`, `getDmsFolderTree`, `getDmsFolderById`, `getDmsFolderChildren`).
2. Storage statistics and quota visualization (`getDmsMyStorage`).
3. Universal document listing, folder document filtering, and previewing (`getDmsAllDocuments`, `getDmsDocumentsByFolder`, `downloadDmsDocument`).
4. File & folder operations:
   - Creation (`createDmsFolder`).
   - Editing & Renaming (`updateDmsFolder`, `updateDmsDocument`).
   - Moving between folders (`moveDmsFolder`, `moveDmsDocument`).
   - Single & batch deletion (`deleteDmsFolder`, `deleteDmsDocument`).
   - Single & bulk file uploads (`uploadDmsDocument`, `uploadDmsDocumentsBulk`).
   - ZIP archiving & single file downloads (`downloadDmsFolderZip`, `downloadDmsDocument`).
5. Role-based collaboration & access control:
   - Shared with me & shared with others (`getDmsSharedWithUsers`, `getDmsSharedWithOthers`, `getDmsDocumentsSharedWithMe`, `getDmsDocumentsSharedWithOthers`).
   - Share invitation & access management (`createFolderShare`, `updateFolderShare`, `deleteFolderShare`, `createDocumentShare`, `updateDocumentShare`, `deleteDocumentShare`, `getFolderShares`, `getDocumentShares`).
   - Activity audit trail logging (`getDmsFolderActivity`, `getDmsDocumentActivity`).
