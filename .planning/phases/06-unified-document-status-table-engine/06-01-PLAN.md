# Plan 06-01: Shared Document Status Table Engine Component & Logic

## Objective
Design and implement a centralized, reusable `<DocumentStatusTable />` component with helper utilities (`statusTableConfig.js`) in `src/Components/DashboardStatuses/DocumentStatusTable/` that consolidates common table rendering, column widths, status chip badges, pagination, empty states, and toolbar layouts across all dashboard document lists.

## Context
Currently, each status screen (`DraftDocs.js`, `CompleteDocs.js`, `DeclinedDocs.js`, `RecallDocuments.js`, `InActive.js`, `PendingDocs.js`, `RecentDocsHome.js`) duplicates:
1. TableContainer wrapping with hardcoded heights (`height: "60vh"`, `height: "70vh"`, `height: "68vh"`).
2. TableHead with repetitive column iterations and inconsistent styles.
3. Empty state row with colSpan and icon/message centering.
4. Pagination calculations and summary strings (`{page * rowsPerPage + 1} - ... {t("tablesLabel.documentsof")} ...`).
5. Status chip styling with inconsistent inline styles or hardcoded hex colors (`#19d157`, `rgb(22, 163, 74)`).
6. Date formatting helpers (`formatDate`).

## Proposed Architecture
1. **`statusTableConfig.js`**:
   - `formatTableDate(dateString)`: Formats dates with Day/Month/Year - HH:MM AM/PM safely.
   - `getStatusBadgeClass(status)`: Maps status keys (`Completed`, `Pending`, `Draft`, `Declined`, `Recalled`, `InActive`, `Active`) to tokenized classes (`bg-emerald-100 text-emerald-800 dark:bg-emerald-950/60 dark:text-emerald-300`, `bg-amber-100 text-amber-800 ...`, `bg-rose-100 text-rose-800 ...`, `bg-slate-100 text-slate-700 ...`, `bg-indigo-100 text-indigo-800 ...`).
   - `computePaginationRange(page, rowsPerPage, totalItems)`: Returns start index, end index, and total pages with safety against out-of-bounds.
2. **`DocumentStatusTable.jsx`**:
   - Reusable table container with `pendingtable` class, border, card background, and zero decorative box-shadow.
   - **Toolbar**: Title, optional icon, count badge, search/filter drawer container, and optional action buttons.
   - **Table**: Full-width sticky header, tokenized `--modern-raised` header cells, proportional column widths, clean empty states with `<TableEmptyState />`.
   - **Pagination**: Standard responsive bottom bar with summary text and page navigation controls.
3. **`statusTableConfig.test.js`**:
   - Comprehensive unit tests covering date formatting, status badge classes, pagination math, and edge cases.
4. **Re-export**:
   - Export from `src/Components/DashboardStatuses/DocumentStatusTable/index.js`.
